# Suspender
Suspender is a browser extension designed to enhance your browsing experience on web by automatically suspending unused tabs to save memory and processing power.

## Features
- Automatically suspends inactive tabs.

## Usage
Just install the extension and that's it. If tab is unused for 1m (60 seconds) it will be suspended. Suspended tabs will stay where they are but won't use any resources. Once you visit that tab it becomes active again and refreshes itself quickly so you can continue your work

It won't suspend tabs playing any kind of audio, so your YouTube session is safe

## Permissions
The extension requires the `storage` permission to store user settings,`tabs` for suspending them and `alarms` to schedule checks for tabs activity.
